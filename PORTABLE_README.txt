格识 · 本地图片转 Excel
版本 1.0.0 / Windows x64 便携版

【怎么打开】
1. 将压缩包完整解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击“格识.exe”。无需安装 Python、Excel 或其他开发工具。
3. 请保留同级的“_internal”文件夹；只发送一个 exe 文件无法运行。

【使用方法】
1. 点击“选择图片”，或点击“粘贴截图”（快捷键 Ctrl+V）。
2. 图片方向不正确时点击“旋转 90°”。点击原图可以放大查看。
3. 选择自动、有边框或无边框模式，然后点击“识别表格”。
4. 对照原图校对。双击结果单元格即可编辑，Enter 确认，Shift+Enter 换行，Esc 取消。
5. 点击“保存 Excel”，选择文件保存位置。
6. 点击窗口右上角关闭软件。没有后台服务，不需要另外停止进程。

【离线与数据】
运行时不需要网络或账号；图片、识别及 Excel 导出均在电脑本地完成。
图片和识别结果不会自动存盘；关闭软件会丢失未保存的结果，请先导出。
单元格以文本保存，保留 00123、长编号及以“=”开头的原文；不会执行公式。
Excel 表格可用 Microsoft Excel、WPS 等兼容软件打开。生成文件本身无需安装 Excel。

【适用范围】
适合清晰的中英文印刷体表格。一次处理一张图片、一个主要表格。
有边框模式可还原简单矩形合并单元格；界面按基本行列显示，合并效果在导出的 Excel 中保留。
合并区域的内容集中在左上角；如需编辑其他格，可先点击“取消合并”。
无边框模式根据文字位置推断行列，跨行、空白及复杂布局可能错列。
淡黄色行含低置信度文字；未标黄的文字也可能有错，需要校对。
不保证恢复原图字体、颜色或列宽。手写、模糊、倾斜拍照和复杂排版可能识别不准确。
建议先裁剪到单个表格。最大 24 MB、2500 万像素；识别最长边缩小为 2800 像素。

【运行环境】
面向 Windows 10 / 11 64 位电脑；不适用于 macOS 或 Windows 32 位系统。
无须管理员权限。已在当前 Windows 电脑通过便携包测试，其他机器兼容性仍以实际运行为准。
首次识别要加载模型，请稍候。程序文件未做商业数字签名。
如果启动或识别失败，日志位于：%LOCALAPPDATA%\GezhiOCR\desktop.log

【分享给别人】
直接发送整个发布压缩包即可，不要只发 exe 文件。包内没有你的图片和识别历史。
“示例图片”里仅包含随软件生成的演示表格，可用于首次测试。
第三方开源组件说明与许可证见“开源许可”文件夹。
